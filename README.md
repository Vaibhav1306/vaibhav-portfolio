# Vaibhav Shrivastava — Portfolio

## Setup
1. Clone the repo
2. Run `npm install`
3. Create `.env` file: `VITE_GEMINI_API_KEY=your_key_here`
   - Get free key at https://aistudio.google.com
4. Run `npm run dev`

## Deploy to Vercel (free)
1. Push to GitHub
2. Go to vercel.com → Add New Project → Import repo
3. Add environment variable: `VITE_GEMINI_API_KEY` = your key
4. Click Deploy — live in 2 minutes
